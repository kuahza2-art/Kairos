# Kairos — Student Council 2027

Campaign website for Cheryl and Nicole, Candidate #2. Includes campaign programs, candidate introductions, and credits.

## View locally

Open `index.html` in a browser, or run `npm start` with Node.js and visit http://127.0.0.1:4174. No dependencies or build step required.

## Files

- `index.html`: campaign website
- `credits.html`: contributor credits
- `assets/`: posters, logos, artwork, and decorative clouds
- CSS files: layout and styling

Google Fonts load online with system font fallbacks. The campaign share button copies text during local preview and shares a link when hosted. Voting and volunteer registration are not connected to a backend.
