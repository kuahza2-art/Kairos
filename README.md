# Kairos campaign website

The complete website is in this folder, including all images and styling.

- `index.html`: page content, candidates, mission, vision, and four campaign ideas
- `styles.css` and `sky.css`: layouts, clouds, colors, and responsive styling
- `script.js`: campaign sharing
- `assets/`: updated campaign poster, approved Kairos logo, supplied artwork, clouds, and paper planes

Open `index.html` in a browser, or use Live Server in VS Code. No installation or build is required. Google Fonts load when online; system fonts work offline.

The website uses the corrected poster supplied on November 12, 2026. Cheryl is the presidential candidate, and Nicole is the vice-presidential candidate. Campaign descriptions are edited for grammar and readability. The supplied poster image is preserved as provided.

“Vote #2” leads to the closing campaign section; no online voting system is connected. The volunteering idea describes the planned Google Form, but no form link has been supplied. During local preview, the share button copies campaign text; after hosting, it shares the website link.
